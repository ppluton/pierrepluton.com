# RAG case-study design

## First iteration

The RAG case is the pilot for the portfolio design review. It uses the existing Manrope typeface and theme variables: paper `#f8f9fc`, ink `#24204c`, accent `#5740ed`, soft `#efedf7`. Dark mode inherits the existing theme. The composition pairs a short introduction with one explanatory architecture panel; the rest of the page connects decisions, measured results and evidence.

The four native disclosure elements form a sequential explanation, not a live inference demo. They remain usable without JavaScript. Motion is limited to disclosure content and action feedback, with reduced-motion support. Both French and English use the same component.

No interface screenshot was found in the audited repository tree. The explanatory architecture must not be described as an actual product screenshot. Add an authentic capture once available.

Metrics remain historical: the 16 January 2026 evaluation recorded 12 questions (9 RAG requests, 3 conversations) with 2.412 seconds mean latency. This does not demonstrate general response quality or present deployment performance.

## Next iterations

Apply the visual approach to professional product cases using authentic web/mobile captures, then simplify Skills page entry points and improve the background timeline. Validate the pilot before expanding the design to all pages.
