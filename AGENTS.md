# Portfolio Pierre Pluton

Independent personal portfolio. Do not change LGDM, Unifête or other projects.
Use Astro static output and preserve accessible navigation without JavaScript.
Keep roles and educational project status accurate. Do not invent client outcomes.

## Development servers

Always use Portly to start, stop, inspect and manage development servers.
Start with `portly status --json`. Reuse healthy matching servers. For bounded previews use `portly temp` with a timeout. Never launch an unmanaged background server.

## Verification

Run `npm run check` and `npm run build`. Verify desktop/mobile, project links, navigation, reduced motion and project detail pages in the browser.
