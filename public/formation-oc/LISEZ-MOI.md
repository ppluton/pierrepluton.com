# Bilan AI Engineer — Pierre Pluton

Situation au 9 octobre 2026. Période : juillet 2025 à octobre 2026.

Pour explorer les relations entre projets et compétences, ouvrir `carte-interactive.html` dans un navigateur. Les sélections et les liens vers les fiches fonctionnent localement, sans installation et sans serveur.

Pour lire le bilan d’un seul tenant, ouvrir `rapport-complet.html` ou `rapport-complet.md`. Chaque projet possède aussi une fiche indépendante, de `projet-p01.html` à `projet-p14.html`.

Les cartes et graphes sont fournis en SVG et PNG. Le graphe des dépôts couvre les 26 dépôts publics ; le graphe des acquis relie les 14 projets OC aux neuf domaines. La matrice contient 55 compétences étayées.

`competences.csv` et `depots.csv` sont réutilisables dans un tableur. `audit.json` conserve les correspondances et les références.

Les liens GitHub des sources sont fixés sur les révisions inspectées. Leur consultation et les pages OC nécessitent Internet ; OC nécessite également l’accès au compte étudiant. Les applications elles-mêmes n’ont pas été lancées pendant l’audit.

J = retour du jury/mentor ; C = code ou document consulté ; R = résultat enregistré. Ces codes ne sont pas des notes de maîtrise. Les acquis issus des dépôts complémentaires sont décrits séparément et n’augmentent pas le décompte des projets OC.

P14 est validé, selon la confirmation de Pierre reçue le 11 octobre 2026. P5 est globalement validé, mais sa compétence d’authentification est indiquée non validée. Les ZIP remis à OC n’ont pas été comparés aux dépôts publics ; les livrables P3 et P9 reposent ici sur les retours OC.

Le dossier compressé réunit les livrables finaux. Il ne contient ni copie brute des dépôts, ni environnement d’exécution, ni clé d’accès. Aucun élément n’a été publié sur GitHub ou OpenClassrooms.
